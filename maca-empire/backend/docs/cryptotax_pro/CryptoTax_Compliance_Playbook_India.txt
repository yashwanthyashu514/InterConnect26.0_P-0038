Crypto Tax Compliance Playbook (India)

Data Model Requirements:
- User profile: residential status, PAN, entity type.
- Transaction events: buy, sell, swap, transfer, staking rewards, airdrops, mining receipts.
- Valuation: INR conversion at event timestamp with source exchange rate.
- Counterparty context: exchange, wallet, self-transfer markers.

Monthly Controls:
1. Reconcile all wallets and exchanges.
2. Classify taxable transfer events and non-taxable internal movements.
3. Compute gains/losses with cost basis method approved by policy.
4. Identify TDS applicability and shortfalls.
5. Produce exception report for missing rates, unknown counterparties, and duplicated tx hashes.

Quarterly Controls:
1. Review unusual gains/losses and outliers.
2. Validate TDS deposits and returns where applicable.
3. Verify supporting documents for high-value transactions.

Year-End Controls:
1. Final gain summary by asset and by exchange.
2. TDS reconciliation statement.
3. Disclosure support pack for tax return filing.
4. Management representation and sign-off trail.

Common Risk Areas:
- Duplicate import of the same transaction hash.
- Missing INR rate for low-liquidity tokens.
- Mislabeling swaps as non-taxable transfers.
- Ignoring gas/fees impact in net consideration.

Audit Evidence:
- Immutable transaction export snapshots.
- Rate-source logs.
- Policy documents for classification and valuation.
- Reviewer sign-off records.
